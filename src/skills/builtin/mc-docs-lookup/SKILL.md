# Minecraft docs lookup

Extraia edição, versão, loader, mappings e JDK dos arquivos do projeto. Pesquise primeiro
docs oficiais do loader/jogo e referências da versão exata; confirme no código ou fontes
geradas quando a API for ambígua. Distingua preview, experimental e estável. Não reutilize
snippets de outra versão sem comparar assinatura, imports, IDs e lifecycle.

Quando a resposta depender de fonte externa, cite URL e versão consultada. Se a fonte não
estiver acessível, diga o que foi inferido e entregue uma checagem local (por exemplo,
Gradle compile), sem apresentar memória do modelo como documentação verificada.

Referências iniciais: https://docs.fabricmc.net/develop/ · https://docs.neoforged.net/ ·
https://learn.microsoft.com/minecraft/creator/
