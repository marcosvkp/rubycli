# Modelos Blockbench

Descubra formato de destino (Java, Bedrock, OptiFine, GeckoLib), escala, pivots, animações
e estado dos arquivos. Se Blockbench MCP estiver configurado, use apenas as ferramentas
reais expostas e valide o modelo antes de exportar. Sem integração, produza/edite arquivos
do projeto com cuidado ou explique como abrir no Blockbench; não presuma que o MCP está
instalado.

Não use `risky_eval`/execução arbitrária para tarefas de modelo quando tools declarativas
forem suficientes. Preserve cópia de modelos existentes e confirme mudanças destrutivas.
Crie textura original ou com licença apropriada, nunca copie assets vanilla. Depois confira
hierarquia, UV, atlas e export format; preview não prova render no jogo.
