# Minecraft launcher MCP

Descubra se um launcher MCP/CLI (por exemplo Polymerium) está realmente configurado e
quais tools oferece. Se não estiver, não instale nem invente comandos; ofereça instruções
manuais ou peça que o usuário configure o servidor MCP.

Antes de alterar instâncias, confira nome, diretório, versão, loader e mods existentes.
Não remova, substitua, atualize ou inicie um perfil sem autorização compatível com o pedido.
Use uma instância de teste descartável para validar o mod e registre a versão efetivamente
aberta. Não distribua assets ou arquivos de jogo. Diferencie instância preparada de jogo
iniciado e teste concluído.
